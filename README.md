# CopilotWith Modernisation Mission Control

An interactive customer accelerator that opens with the art of possibility for GitHub Copilot, introduces CopilotWith as the governed programme model, and provides a separate studio of source-grounded application demos. The existing rich Modernisation Mission Control remains the programme journey.

This is an application-like control room, not a CopilotWith information site.

## Live experience

[Open Modernisation Mission Control](https://ravi0130.github.io/CopilotWith-RVAS/)

## The mission

1. Explore how GitHub Copilot can help teams understand, plan, code, test, secure, deliver, and operate software.
2. Enter CopilotWith to see how those capabilities become a governed modernisation programme.
3. Open the persistent **Demos** destination and compare three independent Before / Modernisation Plan / After journeys: modern .NET eShop, legacy Contoso University, and Spring PetClinic on AKS.
4. Watch .NET, COBOL, Progress, Uniface, Liferay, middleware, HDInsight, and Azure DevOps estates route to specialist packs.
5. See Estate Intelligence and Governed Execution operate as one evidence-led loop.
6. Explore 11 specialist routes with their agents, skills, method, inputs, outputs, maturity, and guardrails.
7. Run the preserved Understand, Protect, and Deliver deep replay against the source-grounded Microsoft eShopOnWeb structure.
8. Inspect the 127-definition CopilotWith agent library and replayed handoffs.
9. Change priorities and customer constraints, then approve a bounded plan.
10. Transform an illustrative MSMQ publisher and review build, test, security, container, and pull-request evidence.
11. Generate portfolio waves and explore the five-level controlled adoption model.

Autoplay handles the first act without presenter input and deliberately stops at architecture approval. Three persona controls change the estate emphasis for executives, architects, and developers.

## Run locally

Requires Node.js 20 or later.

```powershell
npm install
npm run dev
```

Vite normally serves the app at `http://localhost:5173/CopilotWith-RVAS/`.

```powershell
npm run lint
npm run build
npm run preview
```

## Demo boundary

The current build is a deterministic replay, not a live repository scanner. Demo source facts are grounded in their named repositories or labs; plans, target outcomes, and timed agent activity remain replayed or proposed. The application always distinguishes modern `dotnet/eShop`, the legacy Contoso University migration sample, the Java/AKS PetClinic lab, and the preserved local eShopOnWeb reference replay.

See the [customer demo script](docs/DEMO-SCRIPT.md), [data provenance](docs/DATA-PROVENANCE.md), and [architecture](docs/ARCHITECTURE.md).
